# DOOM mode soundtrack

- Track: **At Doom's Gate / E1M1 (DOOM) | GBC 8-bit Demix**.
- Original composition: Robert (Bobby) Prince, DOOM.
- Chiptune arrangement: **TriteHexagon**.
- Author's upload: https://soundcloud.com/user-930339535/e1m1-doom (2020-03-17).
- Local file: `at-dooms-gate-8bit.mp3`, converted from the author's public audio stream for local playback and looping.
- Permission basis: on 2026-10-20 the project requester explicitly reported obtaining permission and instructed the agent to find and use an online version. No public Creative Commons license is asserted; the source lists all rights reserved. Permission correspondence is not included in this repository.

Music plays only in DOOM mode while playing or strolling. The sound setting,
menu and hidden tab pause it. The file is served locally; no streaming widget,
account or external request is needed during gameplay.
