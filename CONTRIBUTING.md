# Участие в проекте

## Предложение или ошибка

Создайте Issue: что изменить, где это находится, как воспроизвести проблему. Для места в парке приложите точку карты или скриншот с отметкой. Не публикуйте чужие личные данные.

## Новый скан

1. Снимите небольшой участок в Scaniverse: медленно, с перекрывающимися ракурсами. Экспортируйте `.spz` и проверьте его через «Открыть .spz» в просмотрщике.
2. Положите облегчённый файл в `captures/YYYY-MM-DD/` с понятным латинским именем. Исходные длинные видео и промежуточные базы в Git не добавляйте.
3. Приложите описание: объект, автор, дата, точка карты, направление съёмки и разрешение использовать скан в проекте. GPS внутри SPZ может отсутствовать. Для нового участка нужны общие ориентиры с соседними сканами.
4. Для просмотра добавьте запись в `capture-scenes.js` по существующему образцу: `name`, `src`, `radius`, `frame` (`cx`, `cz`, `ground`, `top`).
5. Для игры добавьте объект в массив `scans` файла `park/scans.json`, по образцу фонтанов. `at` — положение на карте; `center` — центр исходного скана по X/Z; `ground` — уровень земли; `yaw` — поворот в радианах; `footprint` — полигон коллизии в координатах карты. `src` считается от корня сайта. Новый скан также появится на миникарте.

Координаты карты: X на восток, Z на юг, метры от `origin` в `park/park.json` (широта, долгота). Приближённо: `x = (lon - originLon) * 111320 * cos(originLat * pi / 180)`, `z = -(lat - originLat) * 111320`. Поворот исходного скана нужно подбирать отдельно.

## Отправка изменений

Сделайте fork (для публичного репозитория) либо работайте в своей ветке после приглашения.

```sh
git switch -c add/new-scan
# Edit files and check the result locally.
node --check park.js
node --check app.js
node --check capture-scenes.js
node --check mallards.js
node --test tests/mallards.test.js
python3 -m http.server 8791 --bind 127.0.0.1
```

Проверка крякв и лысух в Google Chrome: при работающем сервере выполните
`python3 tests/mallards_browser.py` (нужен установленный Python-пакет
`playwright`). Проверяются плавание по настоящей карте воды, звуковой выход
и отключение звука, игра с бутылочками, фонтаны и мобильная ширина.
Снимки сохраняются во временный каталог, путь выводится при запуске.

Проверьте игру, просмотрщик и свою сцену. В pull request приложите скриншот результата, перечислите файлы и ограничения. Коммиты и комментарии в коде — на английском; описания для участников — на русском. Не делайте прямые изменения main.

Не добавляйте токены, `.env`, абсолютные пути своего компьютера, символические ссылки на личные папки или сканы без разрешения автора.
