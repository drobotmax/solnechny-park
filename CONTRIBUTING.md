# Участие в проекте

## Предложение или ошибка

Создайте Issue: что изменить, где это находится, как воспроизвести проблему. Для места в парке приложите точку карты или скриншот с отметкой. Не публикуйте чужие личные данные.

## Новый скан

1. Снимите небольшой участок в Scaniverse: медленно, с перекрывающимися ракурсами. Экспортируйте `.spz` и проверьте его через «Открыть .spz» в просмотрщике.
2. Положите облегчённый файл в `captures/YYYY-MM-DD/` с понятным латинским именем. Исходные длинные видео и промежуточные базы в Git не добавляйте.
3. Приложите описание: объект, автор, дата, точка карты, направление съёмки и разрешение использовать скан в проекте. GPS внутри SPZ может отсутствовать. Для нового участка нужны общие ориентиры с соседними сканами.
4. Для просмотра добавьте запись в `capture-scenes.js` по существующему образцу: `name`, `src`, `radius`, `frame` (`cx`, `cz`, `ground`, `top`).
5. Для игры добавьте объект в массив `scans` файла `park/scans.json`, по образцу фонтанов. `at` — положение на карте; `center` — центр исходного скана по X/Z; `ground` — уровень земли; `yaw` — поворот в радианах; `footprint` — полигон коллизии в координатах карты. `src` считается от корня сайта. Новый скан также появится на миникарте.

Координаты карты: X на восток, Z на юг, метры от `origin` в `park/park.json` (широта, долгота). Приближённо: `x = (lon - originLon) * 111320 * cos(originLat * pi / 180)`, `z = -(lat - originLat) * 111320`. Поворот исходного скана нужно подбирать отдельно.

## Отправка изменений

Сделайте fork (для публичного репозитория) либо работайте в своей ветке после приглашения.

```sh
git switch -c add/new-scan
# Edit files and check the result locally.
node --check park.js
node --check app.js
node --check capture-scenes.js
node --check habitat-sites.js
node --check mallards.js
node --check pigeons.js
node --check dogs.js
node --check gulls.js
node --check forest-birds.js
node --check doom-birds.js
node --check small-wildlife.js
node --check jay-voice.js
node --test tests/*.test.js
python3 -m http.server 8791 --bind 127.0.0.1
```

Проверка птиц в Google Chrome: при работающем сервере выполните
`python3 tests/mallards_browser.py` (нужен установленный Python-пакет
`playwright`). Проверяются плавание по настоящей карте воды, одиночные и парные огари,
ходьба и курлыканье голубей, проезд через стаю со взлётом и звуком крыльев,
четыре собаки и вспугивание ими стаи, отключение звука,
игра с бутылочками, фонтаны и мобильная ширина.
Снимки сохраняются во временный каталог, путь выводится при запуске.

Охват всей настоящей карты и соответствие одиннадцати крупных видов птиц местам обитания:
`python3 tests/distribution_browser.py`.

Отдельная проверка тихого синтезированного курлыканья на расстоянии 15–20 м,
длительности до 0,7 секунды, пауз 8–14 секунд и отключения
звука: `python3 tests/pigeon_audio_browser.py`. Она измеряет выход настоящего
Web Audio после пространственного ослабления, без подмены звукового источника.

Лай, дыхание собак только во время бега, пикирование и крик чаек, а также
удаление скамеек проверяет `python3 tests/animals_browser.py`. Он также
проверяет лай при подходе собаки к стае и непрерывный облёт голубей
с возвращением к месту взлёта.

Грачей, серых ворон и дятлов проверяет `python3 tests/forest_birds_browser.py`:
размещение в лесу, карканье, кормёжка на земле, низкий волнистый полёт
с сериями криков, отключение звука и мобильная ширина.

Четырёхкратное количество чаек, одиночное размещение обоих видов дятлов,
полёт и крики больших пёстрых дятлов, 20 плавающих чомг и мобильную ширину
проверяет `python3 tests/additional_birds_browser.py`.

Соек проверяет `python3 tests/jays_browser.py`: 30 одиночных птиц, частые
пространственные хриплые слоги, два мяуканья с интервалом 20 секунд, взлёт при
приближении коляски, отключение звука в настройках и меню, WebGL.

Мелких птиц и белок проверяет `python3 tests/small_wildlife_browser.py`:
места обитания и охват карты, пять трясогузок и 40 белок, три различных голоса
с измерением фактического Web Audio, отключение звука, быстрый облёт воробьёв,
бег трясогузок, перелёты синиц между деревьями, закапывание ореха и мобильная ширина.

Режим DOOM проверяет `python3 tests/doom_browser.py`: код IDDQD, настоящий
музыкальный сигнал, наземная атака всех видов, наезды без столкновения
с коляской, счётчик, неподвижные тела, выключение режима и мобильная ширина.

Проверьте игру, просмотрщик и свою сцену. В pull request приложите скриншот результата, перечислите файлы и ограничения. Коммиты и комментарии в коде — на английском; описания для участников — на русском. Не делайте прямые изменения main.

Не добавляйте токены, `.env`, абсолютные пути своего компьютера, символические ссылки на личные папки или сканы без разрешения автора.
